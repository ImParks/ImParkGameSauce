## 규칙
- **레벨 범위**: 0 ~ 20
- **열정(Passion)**: 없음(0.35× 경험치) / 소소한(1.0×, +8 기분) / 불타는(1.5×, +14 기분)
- **스킬 감쇠**: 레벨 10 초과 시 미사용 스킬 자동 감소
