# 폰 스탯 구조

## 스탯 공식
```
최종 스탯 = (기본값 + Σ오프셋) × Π계수
```

## 신체 능력 (Body Capacities)
| 능력 | 설명 | 영향 받는 스탯 |
|------|------|---------------|
| 의식 (Consciousness) | 전반적 인지 능력 | 대부분의 작업 속도 |
| 이동 (Moving) | 이동 속도 | 이동 속도 스탯 |
| 조작 (Manipulation) | 손/팔 기능 | 사격, 제작, 의료 |
| 시야 (Sight) | 눈 기능 | 사격 정확도 |
| 대화 (Talking) | 언어 능력 | 사회적 스탯 |
| 청력 (Hearing) | 귀 기능 | 사회적 스탯 |

## 주요 스탯
| 카테고리 | 스탯 | 비고 |
|----------|------|------|
| 기본 | 이동 속도, 글로벌 작업 속도 | 항상 표시 |
| 전투 | 사격 정확도, 근접 회피율, 방어력 | 전투 폰 핵심 |
| 제작 | 제작 품질, 의료 치료 품질 | 스킬 기반 |
| 사회 | 협상 능력, 설득 능력 | 외교/거래 영향 |
| 정신 | 정신 붕괴 임계값, 고통 내성 | 생존력 |
