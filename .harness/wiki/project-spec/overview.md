# 림월드 유사 게임 - 프로젝트 개요

## 기본 정보
| 항목 | 값 |
|------|-----|
| 장르 | 콜로니 시뮬레이션 + 생존 + 로그라이크 요소 |
| 서브 장르 | God Game / Base Builder / 간접 제어 전략 |
| 시점 | 2D 탑다운 (타일 기반) |
| 진행 방식 | 실시간 (일시정지 가능, 배속 조절 가능) |
| 세계관 | 미래 SF (행성 개척 / 포스트 아포칼립스 선택 가능) |
| 플레이 방식 | 싱글플레이어 (멀티플레이 미지원) |
| 세션 길이 | 수십~수백 시간 (샌드박스 무한 진행) |
| 승리 조건 | 복수 엔딩 (탈출 / 목표 달성 / 생존 지속) |
| 패배 조건 | 콜로니 전멸 or 핵심 목표 실패 |

## 장르 핵심 특성
- **간접 제어**: 폰을 직접 조작하지 않고 우선순위/구역/명령으로 제어
- **절차적 생성**: 맵, 폰 스탯/특성, 이벤트가 매번 다르게 생성
- **로그라이크**: 퍼머데스 분위기, 각 런이 독립적
- **시뮬레이션 깊이**: 얕은 레이어(건설/자원/전투) + 깊은 레이어(기분/관계/온도/질병)

## 시스템 분류

### Core (필수, 분리 불가)
1. 타일 맵 렌더링
2. 폰 AI (ThinkTree)
3. 니즈(Needs) 시스템
4. 이벤트/스토리텔러
5. 기지 건설
6. 전투 시스템
7. 자원/생산 체인
8. 시간 시스템

### Module (모듈화 가능, ON/OFF)
1. 온도 시스템
2. 관계 시스템
3. 파벌/외교
4. 모딩 지원
5. 질병/의료 심화
6. 동물 시스템
7. 날씨 효과
8. 전력 그리드

## 기술 요구사항 요약
- 2D 타일맵 (최소 256×256, 이상적 512×512)
- 수백 개 폰 동시 렌더링 + AI 처리
- 실시간 + 일시정지 + 4배속
- 폰당 수십 개 스탯/사고 동시 트래킹
- 게임 상태 전체 직렬화 (세이브/로드)
- 데이터 외부화 (Def 시스템, 모딩 지원)
- PC 우선 (Win/Mac/Linux), 소규모 팀 (1~3인)
