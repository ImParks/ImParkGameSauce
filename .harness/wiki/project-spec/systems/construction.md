# 건설 & 공간 시스템

## 타일 기반 구조
- 맵: 정사각형 타일 그리드
- 타일 속성: 지형 유형, 이동 가능 여부, 비옥도, 온도 전도율

## 방(Room) 인식
- 벽 + 문으로 둘러싸인 공간을 **플러드 필(Flood Fill)**로 감지
- 방 통계: 부(Wealth), 아름다움, 공간, 청결

### 인상도 공식
```
인상도 = ((평균(부,미,공,청) + min(부,미,공,청)) / 2) × 100
```
→ 최약 요소가 전체를 지배

## 구역(Zone) 시스템
- **비축 구역**: 아이템 자동 운반, 우선순위 5단계 + 필터
- **재배 구역**: 작물 유형 지정
- **허용 구역**: 폰 이동 범위 제한
- **홈 구역**: 청소/소방/수리 자동 수행 범위
