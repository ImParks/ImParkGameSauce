# 이벤트/스토리텔러 시스템

## 이벤트 카테고리
| 카테고리 | 예시 |
|----------|------|
| ThreatBig | 대규모 레이드, 기계충 감염, 드론 공격 |
| ThreatSmall | 소규모 약탈자, 사나운 동물 |
| Disease | 전염병, 부상 감염 |
| Neutral | 상인 방문, 유성 낙하 |
| Good | 무료 물자 낙하, 방랑자 합류 |
| Environmental | 태양 폭풍, 유독 낙진, 화산 겨울 |

## MTB(Mean Time Between) 확률 모델
```
매 틱마다: P(발생) = 1 - e^(-Δt / MTB)
→ 포아송 과정, 자연스러운 불규칙성
```

## 레이드 포인트 산출
```
레이드 포인트 = (부 포인트 + 폰 포인트) × 위협 스케일 × 경과일 계수 × 적응 계수
```
→ 포인트로 적 유닛 "구매" (유닛별 전투력 값 고정)
