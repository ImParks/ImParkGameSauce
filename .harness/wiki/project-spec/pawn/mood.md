# 기분(Mood) & 정신 붕괴

## 기분 계산
```
현재 기분값 → 목표값으로 보간 (감정 관성 표현)
```

## 사고(Thought) 누적
- 긍정/부정 사고가 스택으로 쌓여 기분 합산
- 각 사고: 지속 시간, 기분 수치, 최대 스택 수 정의

## 정신 붕괴 3단계
| 단계 | 기분 임계값 | MTB | 예시 |
|------|-------------|-----|------|
| 경미 | < 35% | ~3일 | 폭식, 방 틀어박히기 |
| 중대 | < 20% | ~1.2일 | 시체 강박, 정신병적 방황 |
| 극단 | < 5% | ~0.7일 | 광폭화, 야생화, 살인 충동 |

## 회복
- 카타르시스 사고 (+40 기분, 2.5일) → 연쇄 붕괴 방지
