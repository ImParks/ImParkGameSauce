# 구현 Phase 0~6

## Phase 0: 기술 스택 결정
- 엔진(Unity/Godot/커스텀), 언어, AI(BT/GOAP/HTN), 경로탐색, Def 포맷, 직렬화, 모딩
- 각 에이전트가 도메인 관점 평가 → 종합 비교표 → 사용자 승인
- 산출물: tech-stack-decision.json

## Phase 1: 엔진 코어 (core-engine, ui-data)
- 1A: ECS 프레임워크 기본
- 1B: Def 로더 + DefDatabase + 모딩 기반(로드 순서, 패치/오버라이드, mod.json)
- 1C: 이벤트 버스 (토픽, 동기/비동기, IEventBus)
- 1D: 타일맵 시스템
- 1E: 시간 시스템 + 틱 루프 (← 1A+1C)
- 1F: 모듈 레지스트리 IGameModule (← 1A+1C)
- 병렬: 1B/1C/1D는 1A 후 동시

## Phase 2: 폰 기초 + 경로탐색 (pawn-ai, core-engine)
- 2A: 경로탐색 A* + 리전 (독립, 타일맵만 필요)
- 2B: 폰 엔티티 + 기본 컴포넌트
- 2C: AI 행동트리 프레임워크 (← 2B)
- 2D: 니즈 기본 - 배고픔/수면/기분/사고 TTL (← 2B)
- 2E: 신체 부위 트리 + 체력 - 계층구조, 부위별 HP/출혈/통증 (← 2B)
- 병렬: 2A 독립, 2C/2D/2E는 2B 후 동시

## Phase 3: 건설+경제+환경 기초 (building-economy, pawn-ai, environment-life)
- 3A: 건물 배치/해체 + 방(Room) 인식 플러드 필
- 3B: 구역 4종 - 비축(필터/우선순위5단계), 재배(작물/비옥도), 허용(이동제한), 홈(소방/청소)
- 3C: 자원 계층(4단계 가공) + 품질 7단계(끔찍~전설, 가치/성능 배율)
- 3D: 빌 큐 - 레시피/반복모드/재료필터/품질범위/작업자제한 (← 3A+3C)
- 3E: 관계 - 가족/연인/친구/적, 수치(-100~+100), 사회적 상호작용
- 3F: 레크리에이션 관용도 - 10가지 오락, tolerance 0~1 감쇠, 만족도=기본효과×(1-tolerance)
- 3G: 온도 - 타일별 열전도, 단열, 냉난방 (← 3A 방 인식)
- 병렬: 3A/3B/3C/3E/3F 동시, 3D는 3A+3C 후, 3G는 3A 후

## Phase 4: 고급 시스템 (전체)
- 4A: 전투 - 원거리/근접/엄폐/방어구/신체부위별 피해 (← 2E+3C)
- 4B: 전력 - 발전/배터리/소비 그래프 (← 3A)
- 4C: 날씨 - 6종, 온도/작물/기분 연동 (← 3G)
- 4D: 질병/의료 - 감염/만성/수술/인공신체 4티어 (← 2E)
- 4E: 동물 - 야생/길들이기/방목/전투 (← 2C)
- 4F: 이벤트/스토리텔러 3종 + MTB + 레이드 포인트 (← 2D+3C)
- 4G: 기분/정신붕괴 3단계(경미<35%/중대<20%/극단<5%) (← 2D+4F)
- 병렬: 4A~4F 선행조건별 개별 시작, 4G는 4F 후

## Phase 5: UI + 세이브 + 외교 (ui-data, world-event)
- 5A: UI 프레임워크 + HUD + 오버레이 히트맵 (Phase 1 후 조기 착수 가능)
- 5B: 세이브/로드 + 마이그레이터 체인 (Phase 1 후 조기 착수 가능)
- 5C: 파벌/외교 - 적대/중립/우호, 선물/교역/동맹

## Phase 6: 모딩 완성 (ui-data)
- 모딩 API 노출 (이벤트 훅, UI 확장, AI 확장)
- Def 핫 리로드 (개발 모드)
- 모드 매니저 UI, 충돌 해결

## Phase 의존 DAG
```
Phase 0 → Phase 1 (1A→1B/1C/1D 병렬→1E/1F)
            ├→ Phase 2 (2A 독립 | 2B→2C/2D/2E 병렬)
            │    └→ Phase 3 (3A/3B/3C/3E/3F 병렬 → 3D/3G)
            │         └→ Phase 4 (4A~4F 선행조건별 → 4G)
            │              └→ Phase 5C
            ├→ Phase 5A/5B (조기 착수)
            ├→ Phase 1B 모딩 기반 ──→ Phase 6
            └→ Phase 6 (최종)
```

병렬 핵심:
- Phase 2C/2D/2E + Phase 3A/3B/3C (2A/2B 완료 후)
- Phase 5A/5B는 Phase 1 직후 시작 가능
- Phase 4 항목들은 선행조건만 만족 시 개별 시작
