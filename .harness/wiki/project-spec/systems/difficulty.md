# 난이도 시스템

## 구조
```
난이도 = AI 스토리텔러 유형 × 하드코어 설정값 조합
```

## AI 스토리텔러 3종
- **클래식 (Cassandra형)**: 예측 가능한 주기, 점진적 위협 증가
- **자유 (Randy형)**: 완전 랜덤, 좋은/나쁜 이벤트 혼재
- **캐주얼 (Phoebe형)**: 긴 평화 기간, 낮은 위협 빈도

## 조절 가능 변수
| 변수 | 설명 |
|------|------|
| 위협 스케일 | 레이드 규모 배율 (0.5x ~ 5.0x) |
| 이벤트 빈도 | MTB 배율 |
| 폰 사망 시 패널티 | 소프트/하드 |
| 자원 풍부도 | 채굴량, 수확량 배율 |
| 적 AI 공격성 | 공격 전략 복잡도 |

## 동적 난이도 조절
- **부(Wealth) 기반**: `레이드 포인트 = f(아이템 가치, 건물 가치, 폰 수, 경과 일수)`
- **적응 시스템**: 피해 받으면 위협 강도 일시 감소
- **인구 의도**: 폰 수 부족 시 합류 이벤트 증가
