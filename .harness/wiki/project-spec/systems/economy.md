# 생산/경제 시스템

## 자원 계층
```
원재료 → 1차 가공 → 2차 가공 → 완제품
  ↑ 채굴/재배/사냥    ↑ 제련/도살   ↑ 제작대
```

## 빌(Bill) 큐 시스템
- 작업대별 Bill 리스트 (우선순위 순)
- Bill 속성: 레시피, 반복 모드, 재료 필터, 품질 범위, 작업자 제한
