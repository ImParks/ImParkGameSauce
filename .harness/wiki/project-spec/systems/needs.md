# 니즈(Needs) 시스템

모든 니즈: **0.0 ~ 1.0 float**, 시간에 따라 감쇠

| 니즈 | 감쇠 방식 | 충족 방법 | 0% 결과 |
|------|-----------|-----------|---------|
| 음식 | 1.6 영양/일 선형 감소 | 식사 | 영양실조 → 사망 (~72시간) |
| 수면 | 깨어있는 동안 선형 감소 | 수면 (침대 품질 영향) | 즉시 기절 |
| 레크리에이션 | 느린 선형 감소 | 오락 활동 (10가지 유형) | 기분 패널티 누적 |
| 편안함 | 비대칭 (빠른 상승/느린 감소) | 고품질 가구 | 기분 패널티 |
| 아름다움 | 위치 기반 실시간 계산 | 미적 환경 조성 | 기분 패널티 |
| 약물 | 특성/중독 여부에 따라 다름 | 약물 복용 | 금단 증상 |

## 레크리에이션 관용도(Tolerance)
- 동일 유형 반복 → 관용도 상승 → 효과 감소
- 다양한 오락 시설 필요 동기 부여
